# 数智社科实训平台页面概况

> 本文档只描述页面范围、页面结构、展示内容、交互入口和设计图。业务对象、流程、状态含义、权限规则及数据处理规则统一以[《业务流程》](业务流程.md)为准，不在本文重复定义。

## 1. 页面范围与通用布局

平台仅包含桌面端客户端和管理端，统一使用个人用户账号。

| 平台 | 页面定位 | 主要页面 |
|---|---|---|
| 客户端 | 面向个人用户的学习与资源使用入口 | 账号、首页、课程学习、数据资源、实训助手、个人中心 |
| 管理端 | 面向具有相应权限用户的管理入口 | 用户列表、角色与权限、课程模板、数据资源、班级管理、平台设置 |

用户访问未登录可见范围之外的页面时，统一进入登录页。管理端菜单、页面和操作按钮按当前用户权限展示。

业务页面统一采用以下布局：

- 客户端和管理端页面顶部均以模块图标、页面名称和页面描述组成标题区；管理端页面级操作与返回上一级入口集中放在标题区右侧，并与列表页多选操作按钮使用统一高度，返回入口沿用客户端的图标、描边与间距样式；
- 存在上级页面时，标题区右侧显示“返回上一级”，一级页面不显示；
- 新增、保存、导入、导出等页面级操作放在内容区操作栏；
- 仅作用于单个卡片或列表项的操作放在对应对象附近或“更多”菜单中；
- 操作按钮按作用范围统一层级：当前页面唯一的主操作和弹窗确认使用实心按钮；返回、页面级次要操作、多选操作、表单辅助操作与弹窗取消使用 outlined 按钮；表格行、卡片、文件、目录项等对象内部的查看、编辑、下载、删除和“更多”使用 text 按钮；危险操作沿用所在层级，outlined 使用红色描边，text 使用红色文字；
- 同一操作区最多突出一个实心主按钮，text 按钮通过文字颜色与悬停底色反馈交互，不额外使用常驻边框；筛选、分页、标签页和富文本工具栏等选择型控件沿用各自控件样式，不套用操作按钮层级；
- 管理端数据表格统一提供“筛选条件”和“字段设置”：字段设置紧跟在筛选条件之后，二者位于工具栏左侧，不与右侧多选操作混排；每个可筛选字段在“筛选条件”中拥有独立输入控件，常用条件、已生效条件及条件数量在紧凑工具栏中呈现，不将全部筛选控件平铺；筛选弹层覆盖展示且不改变表格布局，弹层中的文本输入、选择、日期和范围控件统一为 36px 高度；“字段设置”可配置各列的隐藏、展示和拖拽排序，并支持恢复默认；
- 管理端数据表格仅在存在多选操作时显示表头与行多选框；不存在多选操作时不显示选择列；
- 管理端数据表格对名称、数量、状态、进度、成绩和时间等有排序价值的字段提供升序、降序和取消排序，表头展示当前排序状态；
- 管理端表格的同类字段顺序保持一致；涉及用户信息时统一优先按用户名、手机号、邮箱、姓名、学院、专业、班级、学号的相对顺序展示，未出现的字段直接跳过；
- 管理端表格数据不脱敏展示，模型密钥等安全凭据除外；日期时间统一使用“YYYY-MM-DD HH:mm”，仅有日期语义时使用“YYYY-MM-DD”，暂无字段值统一使用“—”；
- 管理端侧边导航平铺展示“用户列表、角色与权限、课程模板、数据资源、班级管理、平台设置”，并随完整页面高度延伸；侧边栏左下角展示管理工作台与权限说明；管理端顶部的收起侧边栏按钮右侧不重复展示工作台名称或描述；
- 管理端列表页不展示与当前操作无直接关系的总览统计卡片；课程模板编辑、班级课程编辑等信息量较大的工作页保留课程总览；
- 管理端筛选、字段设置和多选操作使用统一的紧凑单行工具栏，筛选与字段设置靠左、多选操作靠右；选择数据后的操作不使用“批量”前缀；
- 管理端表格包含多个行内操作时统一收纳到“更多”，设计图默认展开第一行的操作菜单，用于展示当前表格支持的单条操作；仅有一个行操作时直接平铺按钮，不使用菜单；操作列使用固定最小宽度，表头、表体和按钮统一右对齐且不得超出表格右边界，弹出菜单与按钮右侧对齐，菜单项使用统一高度并自然撑开菜单容器；用户列表在筛选栏右侧独立提供分配角色、调整状态、删除用户等多选操作，用户启用和停用统一使用“调整状态”；
- 管理端带分页的表格在表格正下方使用独立分页区，左侧展示数据总数，中间展示页码与翻页按钮，右侧使用每页数量选择框，管理员可切换每页显示数量；
- 管理端所有新增类操作统一使用“新增”命名，按钮只显示操作名称，不在文字左侧重复展示加号图标；
- 删除、覆盖、重新导入等高影响操作使用确认弹窗呈现影响摘要，具体处理规则见《业务流程》。

## 2. 客户端

### 2.1 页面结构

```text
客户端
├── 登录
├── 注册
├── 忘记密码
├── 首页
├── 课程学习
│   ├── 课程总览
│   └── 课程详情
│       ├── 学习内容
│       ├── 在线作业
│       └── 课程成绩
├── 数据资源
│   ├── 资源总览
│   └── 资源详情
├── 实训助手
└── 个人中心
```

### 2.2 账号页面

| 页面 | 展示与交互 |
|---|---|
| 登录 | 提供密码登录与验证码登录切换；密码登录可输入用户名、手机号或邮箱，验证码登录可切换手机号或邮箱；提供注册和忘记密码入口 |
| 注册 | 输入手机号、验证码、密码并提交；提供返回登录入口 |
| 忘记密码 | 可切换手机号或邮箱验证，完成验证后在当前页面设置新密码；提供返回登录入口 |

### 2.3 首页

首页用于汇总当前用户信息与近期活动，包含：

- 今日学习概览、用户问候、进行中课程与未完成作业数量；
- 当前班级课程、最近学习章节、学习进度和继续学习入口；
- 进行中课程、待完成作业、已完成作业和最近有效成绩概览；
- 按班级课程归属展示的未完成作业列表、草稿状态和答题入口；
- 最近使用的数据资源及查看入口；
- 顶部用户菜单及个人中心、退出登录入口。

### 2.4 课程学习

#### 课程总览

展示当前用户已加入班级对应的课程，并提供加入班级入口。

| 功能区域 | 展示与交互 |
|---|---|
| 学习概况 | 展示已加入班级、进行中课程、待完成作业和已结课课程数量 |
| 课程筛选 | 支持按课程名称、班级和学习状态筛选，并按最近学习时间排序 |
| 课程卡片 | 展示课程名称、所属班级、教师、学习状态、学习进度和待完成作业；点击进入课程详情 |
| 加入班级 | 打开班级码输入弹窗；校验通过后分区展示班级、课程和教师信息，确认后提交；校验结果和加入规则见《业务流程》 |

#### 课程详情

课程详情对应一个班级课程实例，顶部集中展示课程名称、所属班级、教师、课程说明和学习进度；下方使用独立分段导航提供“学习内容”“在线作业”“课程成绩”三个可直接切换的子页面。

##### 学习内容

| 功能区域 | 展示与交互 |
|---|---|
| 章节目录 | 按章、节展示课程结构、当前选中项和学习状态；点击节切换内容 |
| 本节内容 | 展示本节说明和课程附件；提供附件查看或下载、完成本节学习操作 |
| 数据资源 | 展示本节关联资源；可进入资源详情或下载 |
| 本节作业 | 展示作业状态和开始或继续答题入口 |

##### 在线作业

左侧沿用课程章节目录，并展示各节作业状态；目录状态统一显示为“待完成”“答题中”“智能判分中”“待复核”“已完成”，没有作业的节不可选择。右侧题目统一展示题目标题和可选的富文本题目描述，并根据单选、多选、判断、填空、简答、实践六种题型呈现对应作答控件或批改结果；题型标签分为两种统一样式，简答题与实践题使用同一强调样式，其余题型使用同一基础样式；判断题沿用选择题交互样式，使用对钩和叉号图标区分正确、错误，不使用字母序号；简答题使用富文本编辑器，工具栏图标统一垂直居中，编辑器底部仅展示字数统计，不显示自动保存状态文案；实践题的题目附件随题目内容展示、作答附件在独立上传区提交。页面提供保存草稿、提交作业、查看题目得分与反馈等操作，提交确认弹窗展示完成情况、作业摘要和提交后的处理说明。

##### 课程成绩

展示课程总成绩与作业成绩明细。明细包括作业名称、得分、权重、加权得分和批改状态；待复核且尚无有效得分时，得分单元格使用“—”占位。表格各状态行保持统一高度，并提供进入对应作业的入口。

### 2.5 数据资源

| 页面 | 展示与交互 |
|---|---|
| 资源总览 | 顶部概览展示一级数据分类数和平台资源总量；左侧以目录树浏览资源，右侧一次展示当前所选末级目录的全部资源，不使用分页；资源项展示名称、描述、标签和字段数量，通过紧凑搜索框和标签选择在当前目录内筛选 |
| 资源详情 | 展示资源名称、描述和标签，直接完整展示全部字段说明；提供 CSV 样例预览或下载，以及 ZIP 数据下载 |

目录层级、可选状态和资源可见范围遵循《业务流程》中的数据资源规则。

### 2.6 实训助手

顶部导航提供实训助手入口。页面展示静态功能介绍与使用指引，不包含独立业务流程。

### 2.7 个人中心

个人中心使用一个完整页面展示和维护账号信息：

- 头像、用户名和账号状态；
- 学院、专业、班级、学号、姓名、注册时间和实名状态，并提供实名认证入口；
- 手机号和邮箱使用脱敏值展示，状态统一使用“已绑定”“未绑定”，操作统一使用“修改”“绑定”；
- 登录密码不展示状态，提供“修改”操作；
- 实名认证、联系方式绑定或修改、密码修改均在独立弹窗中完成；
- 实名认证表单按学院、专业、班级、学号、姓名的顺序填写，与实名认证信息的展示顺序保持一致；
- 绑定或修改手机号、邮箱均采用“验证当前账号—绑定新联系方式”两步流程；第一步可在账号已绑定的手机号和邮箱之间切换验证方式，第二步验证并绑定新的手机号或邮箱；各步骤的验证码字段统一显示“验证码”，发送操作统一显示“发送验证码”；
- 最近登录时间和账号安全信息。

## 3. 管理端

### 3.1 页面结构

```text
管理端
├── 用户列表
├── 角色与权限
├── 课程模板
│   └── 课程编辑
│       ├── 本节内容
│       ├── 作业配置
│       └── 题目新增/编辑
├── 数据资源
│   ├── 资源目录与列表
│   └── 资源编辑
├── 班级管理
│   └── 班级详情
│       ├── 成员列表
│       ├── 课程编辑
│       ├── 作业批改
│       └── 成绩管理
└── 平台设置
    └── 模型服务配置
```

### 3.2 用户管理

| 页面 | 展示与交互 |
|---|---|
| 用户列表 | 表格按用户名、手机号、邮箱、姓名、学院、专业、班级、学号、角色、状态、最近登录的顺序展示，手机号、邮箱和其他资料在管理端不脱敏；提供导入用户和新增用户入口；筛选条件分别提供用户名、手机号、邮箱、姓名、学院、专业、班级、学号、角色、状态和最近登录输入控件；多选操作区提供分配角色、调整状态、删除用户；单条数据的查看详情、编辑用户、分配角色、调整状态和删除用户统一收纳到行内“更多”，“查看详情”排列在菜单首位；支持字段显隐及对用户名、姓名、学院、专业、班级、学号、状态和最近登录排序 |
| 角色与权限 | 左侧展示管理角色列表、角色成员数与当前选择，支持新增和切换角色；每个角色通过与课程编辑、数据资源一致的竖向三点“更多操作”菜单提供编辑角色和删除角色，设计图默认展开当前选中角色的菜单，菜单项统一为 30px 高度。右侧 Header 展示角色名称、说明、成员数及已授权数量，只保留保存权限操作，不显示角色类型标签。权限区按“用户列表、角色与权限、课程模板、数据资源、班级管理、平台设置”六个管理端模块分组，每个模块单独占一整行，完整展示查看权限和页面内操作权限；班级管理进一步区分班级、成员、课程实例、作业批改和成绩操作。模块标题支持整组选择，操作权限自动依赖查看权限；“清空权限”使用 Text 按钮。设计图使用课程管理员作为示例，仅配置课程模板维护权限和选择课程资源所需的查看数据资源权限 |

### 3.3 课程模板

#### 模板列表

展示全部课程模板及模板名称、课程结构、作业数量、使用班级数量、创建人和更新时间。筛选条件分别提供模板名称、课程结构、作业数、使用班级、创建人和更新时间输入控件；多选操作区提供复制模板、删除模板；单条模板通过“更多”提供编辑模板、复制模板和删除模板，并提供新增模板入口；支持字段显隐及对模板名称、作业数、使用班级、创建人和更新时间排序。

#### 课程编辑

| 页面区域 | 展示与交互 |
|---|---|
| 基础信息 | 编辑课程标题、描述和封面 |
| 课程结构 | 展示章、节层级；底部统一提供“新增章”入口；章的“更多”菜单提供重命名章、新增节、上移、下移和删除章，节的“更多”菜单提供移动到其他章、上移、下移和删除节，设计图分别默认展开一个章菜单和一个节菜单；两类更多按钮使用同一右侧列，菜单项统一高度 |
| 本节内容 | 编辑节标题、节描述和富文本本节说明；本节说明复用客户端在线作业简答题的富文本编辑器，编辑器底部仅展示字数统计；课程附件提供下载和删除操作，下载位于删除左侧 |
| 数据资源 | 展示当前节已关联资源；通过“选择资源”进行关联，并可解绑 |
| 作业配置 | 创建或编辑当前节作业，仅维护作业状态、成绩权重和题目列表；作业名称由节标题生成，题目数量由列表统计；题目列表逐题展示题目标题，判分流程作为标题下方的辅助信息；题型标签按内容自适应宽度，简答题与实践题使用同一强调样式，其余题型使用同一基础样式；单题编辑与删除收纳到“更多”菜单，并默认展开第一题菜单；在课程结构中同步展示各节作业权重 |
| 题目新增/编辑 | 设置题型、题目标题、题目描述、分值及题型专属答案配置；题目标题和题目描述标签不附加“必填”“选填”或“富文本”说明，题目描述统一复用课程编辑页的富文本样式；题型配置按单选题、多选题、判断题、填空题、简答题、实践题排列；单选题、多选题、判断题和填空题配置标准答案，简答题和实践题配置富文本参考答案；单选题、多选题和判断题的“自动判分”标签按内容自适应宽度；判断题标准答案沿用单选题和多选题的选项行样式，在单选框和“正确”“错误”文本之间复用客户端在线作业判断题的对钩、叉号 SVG 图标，不附加解释文案；判断题不提供删除选项，“标准答案”标签靠选项行右侧对齐；填空题答案与同义答案紧凑排列，每个空格项右侧提供删除操作；实践题可配置题目附件，附件区沿用课程附件的平铺结构，不额外套用卡片；“题目附件”使用与其他表单字段一致的标签样式，不显示辅助描述，上传附件按钮位于附件行下方；不再单独配置学生作答要求 |

本节内容与作业配置编辑区使用紧凑的顶部内边距；右侧不重复展示整门课程统计，在本节内容页以“配置概况”展示课程附件、数据资源和本节作业。

保存校验、判分配置和对已有数据的影响统一遵循《业务流程》。

### 3.4 数据资源

#### 资源列表

页面左侧与课程编辑页的课程结构统一使用相同的卡片内边距、目录行高、层级缩进、圆角选中态、更多按钮和底部操作按钮样式；标题右侧不显示新增图标，底部仅提供“新增目录”入口。目录通过“更多”菜单提供新增子目录、重命名、移动和删除等操作，设计图默认展开一个目录菜单。只有选中末级目录后，右侧才展示该目录的数据资源列表，并在目录标题区依次提供“导入资源”“新增资源”入口；非末级目录仅用于展开和收起目录层级。筛选条件分别提供资源名称、英文名、标签、字段数、样例文件、数据文件、关联课程和更新时间输入控件；多选操作区提供上传样例、上传数据和删除资源。

资源列表按资源名称、资源英文名、标签、字段数量、样例文件、数据文件、关联课程和更新时间的顺序展示；支持字段显隐及对资源名称、英文名、字段数、关联课程和更新时间排序；多选框单元格不显示多余省略号，样例文件和数据文件的状态统一使用“未上传”“已上传”。列表提供 CSV 样例及 ZIP 数据的多选上传入口，单条资源通过“更多”提供编辑资源、移动资源和删除资源。目录和操作的可用状态按《业务流程》中的资源规则控制。

#### 资源编辑

| 页面区域 | 展示与交互 |
|---|---|
| 所属目录 | 单独占一行，选择资源所在的末级目录 |
| 基础信息 | 资源名称和资源英文名排列在同一行，资源描述单独占一行 |
| 资源标签 | 使用简单列表维护标签，支持新增、编辑和删除，并可为每个标签选择展示颜色 |
| 字段说明 | 以表格维护字段、英文名和说明，支持增删与拖拽排序；该表格属于录入控件，不提供列表筛选与字段显隐；操作列固定为刚好容纳红色“删除”按钮的最小宽度；页面内单行输入框与选择框统一为 44px 高度 |
| 样例 | 上传、替换、预览或下载 CSV 样例文件；文件卡片提供下载和替换操作 |
| 数据 | 上传、替换或下载 ZIP 数据文件；文件卡片提供下载和替换操作 |
| 使用情况 | 展示已关联的课程模版、课程实例及对应章节 |

删除、移动或替换资源时，确认弹窗展示关联使用情况和影响摘要。

### 3.5 班级管理

#### 班级管理

表格按班级名称、课程模版、教师、成员数量、状态和创建时间的顺序展示；筛选条件分别提供班级名称、课程模板、教师、成员数、状态和创建时间输入控件；多选操作区提供“调整状态”“删除班级”；单条数据通过行内“更多”提供“编辑班级”“调整状态”“删除班级”，点击班级名称进入班级详情，并提供新增班级入口；支持字段显隐及对班级名称、课程模板、教师、成员数、状态和创建时间排序。

新增班级使用页面内弹窗或抽屉，表单不使用分组标题，仅填写班级名称、选择课程模版并指定教师，不提供班级状态字段；抽屉层级高于遮罩，遮罩仅覆盖并压暗背景页面。提交后的业务处理见《业务流程》。

#### 班级详情

班级详情顶部展示班级基础信息，并提供“成员列表”“课程编辑”“作业批改”“成绩管理”四个可直接切换的管理视图。

| 页面 | 展示与交互 |
|---|---|
| 成员列表 | 表格按用户名、姓名、学号、身份、学习进度、加入时间和操作的顺序展示；身份分为教师和学生，均使用标签呈现，教师与学生均展示学习进度；筛选条件分别提供用户名、姓名、学号、身份、学习进度和加入时间输入控件，不提供加入方式筛选；多选操作区提供“移出班级”，单条数据通过“更多”提供查看详情和移出班级，并保留导入用户和生成班级码入口；支持字段显隐及对用户名、姓名、学号、学习进度和加入时间排序 |
| 课程编辑 | 沿用课程编辑的结构与控件，编辑当前班级课程实例；额外提供“重新导入”入口，确认弹窗底部操作按钮使用统一高度并垂直对齐 |
| 作业批改 | 筛选条件分别提供用户名、姓名、学号、作业、提交时间、提交次数、批改状态和得分输入控件；表格按用户名、姓名、学号、作业、提交时间、提交次数、批改状态、得分和操作的顺序展示；多选操作区提供“确认批改”和“打回重做”，不提供“导出记录”；操作列每行仅平铺一个按钮，待复核显示“批改作业”、已完成显示“查看批改”、智能判分中显示禁用的“批改作业”，不使用菜单；支持字段显隐及对用户名、姓名、学号、作业、提交时间、提交次数和得分排序；可进入详情查看作答、智能判分结果和历史记录，并执行人工复核、确认或打回；批改详情标题区使用“确认批改”，右侧判分区仅展示建议得分、简要说明、人工复核得分与评语，不重复显示完成状态；复核得分使用数值输入与总分后缀组合，并明确智能建议仅供参考；打回重做确认弹窗的“打回原因”标签不附加“必填”文本 |
| 成绩管理 | 表格不提供多选列，按用户名、姓名、学号、已完成作业、已计入权重、当前总成绩、班级排名、状态和操作的顺序展示；筛选条件分别提供用户名、姓名、学号、已完成作业、已计入权重、当前总成绩、班级排名和状态输入控件；每行直接平铺“成绩明细”操作，不使用菜单，并提供导出入口；支持字段显隐及对用户名、姓名、学号、已完成作业、已计入权重、当前总成绩和班级排名排序；成绩明细页的成员信息先展示用户名、后展示学号，作业明细表不提供多选列，筛选条件分别提供作业、权重、得分、加权得分、状态和批改时间输入控件，每行直接平铺“查看作答”，并支持字段显隐及对作业、权重、得分、加权得分和批改时间排序 |

重新导入、成员变更、批改和成绩计算的规则见《业务流程》；页面只负责提供入口、展示状态和承载确认操作。
